# 海上搜救联合指挥 · 可恢复调度账

搜索区、单位、任务单、位置回执全部接进同一本 **append-only 调度账**。岸基与船艇各持一份日志，
断链时各自记账，回网后确定性合并；当前态势永远由日志**回放重建**，因此任何节点崩溃后都可完整恢复。

## 账本不变量

| 需求 | 实现 |
| --- | --- |
| 同一单位序号只入账一次 | 回执携带单位单调 `seq`，条目幂等键 `receipt:{unit}:{seq}`；回放层与合并层双重去重，重复重传进"丢弃/忽略"审计 |
| 字段冲突保留两版待确认 | 改单携带 `baseRev`；离线双方基于同一版改同一字段时，合并挂起为冲突（基版 + 岸版 + 船版），裁定前任何一方都不覆盖 |
| 任务单更新后旧覆盖率失效 | 每次实质更新任务单 `gen+1`；旧 gen 的覆盖率回执标记 `superseded`，搜索区覆盖率**只按当前 gen 有效回执重算**，无有效回执显示"待重算"，不沿用旧值 |
| 过期位置 / 在途位置失效 | 超过 10 分钟的位置标 `stale`；任务更新或关闭后，挂在旧 gen 上的在途位置立即 `superseded`，等待单位按新版重报 |
| 在途任务立即重算 | 在途派属只由"开放任务（非 closed）+ 当前 `unitIds`"派生；任务关闭即从所有单位的在途列表移除，**不会把已结束任务派回旧搜索区**；迟到的"在途回退"指令被拒绝并留痕 |
| 已完成航迹照旧留档 | 关闭任务瞬间把在途轨迹快照为 `TrackArchived` 只追加条目，独立于任务生命周期，永不参与重算或删除 |
| 低带宽可查最近同步结果与未回传单位 | 同步面板固化最近一次 `SyncResult`（新收/去重/新冲突/失效条数、双方账长）；"未回传单位"按回执水线计算；低带宽模式关闭地图瓦片，仅用纯文本呈现态势 |

## 账体结构

```
src/lib/ledger/
├── types.ts   # 条目（注册/开单/状态/改单/位置/覆盖率/航迹/冲突）、投影、同步结果
├── replay.ts  # 纯函数回放引擎：幂等去重 → 冲突挂起 → 失效判定 → 覆盖率/在途派属重算
├── merge.ts   # 岸基/船艇双节点 + 回网双向合并（确定性排序、去重统计）
└── seed.ts    # 预置断链现场：岸基改单并关闭任务+归档航迹+开B区新任务；船艇同时改同字段、失联机补传旧gen回执
```

持久化：Zustand `persist`（`maritime-ledger-v2`）保存双方原始日志；投影不持久化，全部从日志回放。

## 操作流程（预置场景）

1. 打开页面即为**断链状态**：岸基账（关闭 A 区任务、归档海巡071航迹、开 B 区任务）与船艇账（同字段改单、无人机离线补传）分叉。
2. 顶部切换"岸基/船艇"身份，可模拟任意一方继续报位置、报覆盖率、改单、开新任务。
3. 点 **回网合并**：查看同步统计；说明字段出现冲突卡，两版并排、人工裁定；无人机旧 gen 回执全部标失效；A 区覆盖率显示"待重算"；航迹完好留档。
4. 任一单位点"重传旧序号"可验证幂等（计入丢弃/忽略，不改变水线）。
5. 合并后链路保持接通，新写入双发入账；"切断链路"可再次制造分叉。
